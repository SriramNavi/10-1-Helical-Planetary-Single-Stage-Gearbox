# Third-party notices and asset review

| Component | Use | Distribution in this package |
| --- | --- | --- |
| NumPy / SciPy | Numerical arrays, equation tests and quadrature | Imported dependencies only; no library source/binary bundled |
| Matplotlib | Original charts and project-derived geometric illustrations | Generated PNG/SVG output; runtime not bundled |
| trimesh | Sections of project-native tessellation | Generated project-derived contours only; runtime not bundled |
| ReportLab / Python-Markdown | Publication rendering | Generated report/HTML output; runtimes not bundled |
| SolidWorks / Simulation | Native CAD and FEA used in prior evidence | Product acknowledged; no software, bindings, CWR or complete native CAD bundled |
| Built-in PDF fonts / local system fonts | Document display | No separate font binary redistributed |

Installed versions and declared license metadata are recorded in `evidence/DEPENDENCIES.json`. Authoritative license texts remain with the upstream projects: [NumPy](https://github.com/numpy/numpy/blob/main/LICENSE.txt), [SciPy](https://github.com/scipy/scipy/blob/main/LICENSE.txt), [Matplotlib](https://matplotlib.org/stable/project/license.html), [trimesh](https://github.com/mikedh/trimesh/blob/main/LICENSE.md), [ReportLab](https://www.reportlab.com/opensource/), [Python-Markdown](https://github.com/Python-Markdown/markdown/blob/master/LICENSE.md). No external source artwork is copied from the engineering references.

Original native CAD, private FEA/solver archives and unpublished assets are excluded and retain all rights reserved. The owner approved the curated public code and engineering documentation/figures under the scoped licenses. Third-party dependency/reference licenses are unchanged.
