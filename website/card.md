# GB10-V2 - compact planetary transmission investigation

A 10:1 helical planetary gearbox investigated with native CAD measurements, independent Python mechanics and verified structural comparisons. Two local fillet candidates increased predicted peak stress; the original output core was retained. The work demonstrates load-path reasoning, mesh/probe verification and an evidence-based design gate.

Evidence: CAD-derived / analytical / simulated. Hardware performance and torque capacity unverified. Suitable categories: robotics transmissions, mechanical design, structural verification, mechatronics R&D.
